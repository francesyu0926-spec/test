# 采购需求

> 本文档按《山西省市场监督管理局个体工商户保险保障项目·采购需求.doc》章节结构编制，内容来源于《山西神龙能源焦化有限责任公司厂区废液等危险废物处置项目》招标文件（ZLZX 招【2021】0194 号）。

---

## （一）需求清单

### （一）项目概况

山西神龙能源焦化有限责任公司厂区现存新事故池、新调节池、脱硫工段和粗苯工段废液收集池的约 800 余吨废液及污泥、滤袋 1.5 吨、废矿物油和废油桶约 1 吨等危险废物，需委托具备资质的单位完成收集、装卸、道路运输、处置及清理清洗（含池壁、涵洞管沟等）服务，并出具危险废物转移处置完结报告。项目资金来源为企业自筹，服务地点为招标人指定地点（山西省晋中市）。

### （二）采购项目预（概）算

| 项目 | 金额/标准 |
|------|-----------|
| 最高投标限价 | 4000 元/吨（含税） |
| 计价方式 | 处置服务费单价 × 实际过磅量 |
| 预估处置规模 | 约 800 余吨废液及污泥等（以出厂过磅为准） |
| 预估合同金额（参考） | 按实际过磅量结算，投标报价不得超过最高限价 |

### （三）采购标的汇总表

| 包号 | 序号 | 标的名称 | 品目分类 | 计量单位 | 数量 | 是否进口 |
|------|------|----------|----------|----------|------|----------|
| 001 | 1 | 山西神龙能源焦化有限责任公司厂区废液等危险废物处置项目 | 危险废物处置服务 | 项 | 1 | 否 |

### （四）技术商务要求

#### （1）技术要求

**标的：厂区废液等危险废物处置服务**

| 项目 | 要求 |
|------|------|
| 采购人/委托人 | 山西神龙能源焦化有限责任公司 |
| 服务地点 | 委托方厂区或指定地点（山西省晋中市） |
| 服务标的 | 危险废物收集、装卸、运输、处置、清理清洗及完结报告编制 |
| 主要废物来源 | 新事故池、新调节池、脱硫工段、粗苯工段废液收集池等 |
| 预估规模 | 废液及污泥约 800 余吨；滤袋 1.5 吨；废矿物油及废油桶约 1 吨 |
| 结算依据 | 以神龙能源焦化公司出厂过磅数据为准 |
| 危废类别（资质要求） | HW11、HW49、HW08 |
| 处置方式 | 水泥窑协同处置（代码 C1） |
| 服务期限 | 自合同签订后 **45 天内** 完成全部处置并出具完结报告 |
| 质量要求 | 达到国家、行业相关规范、规定合格标准 |
| 环保要求 | 符合国家、山西省有关环保、安全、职业健康等法律法规及行业标准 |

**保障/服务内容一：处置技术服务**

- 对危险废物中有毒、有害物质进行定性、定量分析，根据其理化性质及危险特性，通过相应处置系统输送至水泥回转窑进行高温、无害化处置。
- 按危险废物经营许可证核准的储存、处置方式实施处置。
- 处置完毕后出具《神龙焦化危险废物转移处置完结》报告。

**保障/服务内容二：运输服务**

- 采用具有《道路危险货物运输许可证》且经营范围包含本次危废类别的车辆运输。
- 装车出厂后至合法处置完毕前的安全环保责任由受托方承担。

**保障/服务内容三：装卸及清理清洗服务**

- 负责装车、卸车。
- 清理清洗危废设施内部（含清理清洗池壁、涵洞管沟等），达到发包人要求。

**投标人须提交的方案（纳入评标）**

1. 处置计划及储存废液设施内部清理清洗方案（合理性、可行性纳入评标）。
2. 针对本次处置物品的应急预案、安全防护方案、运输方案。
3. 日处理能力及贮存能力证明材料。
4. 全过程质量管理和控制措施说明。

**特别约定（与合同一致）**

1. 委托方负责危险废物转移联单申请及管理；委派专人交接并监督转移全过程。
2. 转移废物须与检验合格准入样品相符；不符或超标受托方有权拒收。
3. 委托方不得将易制毒、剧毒、放射性、爆炸性、不明物等混入其他危险废物；否则事故责任由委托方承担。
4. 受托方对委托方技术资料保密；未经许可不得向第三方泄露。

**五、其他**

- 投标人须按招标文件要求编制电子投标文件并参加线上开标；辅助纸质投标文件正本 1 份、副本 4 份。
- 投标人须保持关注山西新点招投标交易平台，及时响应评标委员会询问。

#### （2）商务要求

**（一）服务期限：** 自合同签订后 45 天内完成全部处置并出具完结报告。

**（二）服务地点：** 招标人指定地点（山西省晋中市）。

**（三）服务标准：** 达到国家、行业相关规范、规定合格标准。

**（四）服务要求：**

1. 投标人须具有省级生态环境厅（局）核发的《危险废物经营许可证》，危险废物类别为 HW11、HW49、HW08，经营方式、经营类别、经营规模符合招标要求。
2. 投标人须具有公路运输管理部门核发的《道路危险货物运输许可证》，运输经营范围包含本次处置危废类别。
3. 投标人在近五年（2016 年 3 月至今）须具有同类型业绩（以合同为准）。
4. 不允许分包；接受联合体投标时，牵头人须具备有效危险废物经营许可证。
5. 投标报价不得超过最高投标限价 4000 元/吨（含税），报价须包含人工、清洗、装卸、运输、设备、处置等全部费用及招标代理服务费。
6. 质保金承诺纳入评标，预留比例不低于 10%。

**（五）付款方式：**

以合同签订时双方约定为准。招标文件示范合同约定：受托人完成全部委托工作内容并依法出具完结报告后 5 日内，委托人支付款项；具体以双方签订的委托合同为准。

**（六）验收方式及验收标准：**

- 验收依据：合同约定及国家、行业相关规范。
- 验收成果：危险废物处置完结报告（神龙焦化危险废物转移处置完结报告）。
- 实际结算数量以出厂过磅数据为准。

**（七）其他要求**

1. 投标保证金：人民币 60000 元（通过基本账户递交）。
2. 投标有效期：90 日历天。
3. 履约保证金：不要求。
4. 须提供基本账户信息、财务报告（2019 或 2020 年度）、近 3 个月社保（五险）及增值税纳税凭证。
5. 不得列入严重违法失信企业名单；信用中国无不良诚信记录。

## 综合评分法评分细则（摘要）

> 评标办法：经评审的最低投标价法；技术 60 分 + 商务 40 分，折算计入评标基准价。

### 商务服务部分（40 分）

| 评审因素 | 分值 | 评审标准（摘要） |
|----------|------|------------------|
| 投标人业绩 | 0～25 | 2016 年 3 月至今同类项目业绩，每项 5 分，最多 25 分 |
| 服务承诺 | 0～10 | 在满足招标文件基础上自行编写，按完善程度排序评分 |
| 质保金承诺 | 0～5 | 预留比例高者优先；最低 10%；未提供不得分 |

### 技术部分（60 分）

| 评审因素 | 分值 | 评审标准（摘要） |
|----------|------|------------------|
| 投标技术指标响应程度 | 0～15 | 在满足第五章技术指标基础上，描述合理、完整且符合国标 |
| 投入主要设备投入计划 | 0～15 | 计划合理完善程度酌情打分 |
| 安排计划、运输方案、日处理及贮存能力、存放计划 | 0～10 | 安排合理、方案完善、能力充足 |
| 应急预案及措施 | 0～10 | 针对本次处置物品的应急与安全方案 |
| 全过程质量管理和控制 | 0～10 | 描述详细程度酌情打分 |

### 价格部分

- 经评审的最低投标价法：技术、商务排名按权重折算后，**经评审投标价从低到高**推荐中标候选人。
- 最高投标限价：4000 元/吨（含税）。
