## 五、双方核心义务摘要

### 委托人（甲方）

- 提供危废基本信息、应急措施、包装与标签要求等  
- 废物分类包装，不得混装不同性质/类别；不得混入易制毒、剧毒、放射性、爆炸性等高危废物  
- 委派专人交接并监督转移全过程  
- 负责危险废物转移联单申请及管理  
- 转移废物须与检验合格准入样品相符  

### 受托人（乙方）

- 按许可证核准方式实施水泥窑协同处置（C1）  
- 编制或出具转移处置完结报告，对报告质量负责  
- 配合监督，提醒并协助完成危废全过程管理  
- 对甲方技术资料保密  
- 装车出厂后至合法处置完毕的安全环保责任  

## 六、违约责任（备案）

| 情形 | 责任 |
|------|------|
| 受托方服务质量缺陷 | 采取补救措施，自行承担法律及经济风险 |
| 期满未提交符合要求的报告或成果 | 按报酬总额 **1%** 承担违约责任 |
| 委托人影响开工或迟延付款 | 履行期限可顺延；迟延付款按报酬总额 **1%** 承担违约责任 |

## 七、其他备案条款

| 条款 | 内容 |
|------|------|
| 争议解决 | 协商不成，向**委托人所在地**有管辖权人民法院起诉 |
| 合同生效 | 双方签字盖章之日起生效 |
| 不可抗力 | 可解除合同，双方不承担相应责任 |
| 人员聘用限制 | 合同期内及终止后一年内，未经书面同意不得聘用对方参与执行的职员 |
| 合同变更 | 须双方协商一致并书面确定 |
